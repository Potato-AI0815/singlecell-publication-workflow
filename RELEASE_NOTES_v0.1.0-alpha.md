# v0.1.0-alpha

First public alpha of SingleCell Publication Workflow.

Maintainer: Potato-AI  
Repository: https://github.com/Potato-AI0815/singlecell-publication-workflow

## Highlights

- one-click Windows launcher;
- sample-aware Seurat v5 core workflow;
- raw-count pseudobulk safeguards;
- independent publication figures with figure-specific Source Data;
- automatic PASS/WARNING/FAIL QA;
- Seurat v5-compatible layer joining and release-validated source-data manifests;
- public-data validation on mouse cortex and paired colorectal cancer;
- targeted runtime validation of CopyKAT, CellChat and GeneNMF adapters;
- resume-safe figure reuse and lightweight plot proxies.

## Experimental modules

hdWGCNA, trajectory, spatial, drug-response and virtual-knockout functionality remains experimental or partially validated. Read `VALIDATION_MATRIX.md` and `KNOWN_LIMITATIONS.md` before use.
