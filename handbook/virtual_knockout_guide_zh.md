# 虚拟敲除模块使用与解释手册

## 1. 模块定位

本模块使用 `scTenifoldKnk`，从野生型/基线状态的单细胞 RNA 原始计数构建基因调控网络，将目标基因的出边置零，再比较 WT 与虚拟 KO 网络状态。它适合提出基因功能和下游网络影响假设，不等同于真实 CRISPR 敲除实验。

## 2. 为什么不能直接对全部细胞运行

不同谱系混合会使共表达网络主要反映细胞类型差异，而不是目标基因在特定生物学状态中的调控作用。因此默认必须指定一个明确且相对同质的细胞群，例如恶性浆细胞、肿瘤上皮细胞或某个免疫亚群。

## 3. 推荐分析单位

默认采用“每个生物学样本独立运行 + 每个样本重复下采样 + 跨样本共识”。

- 单个样本内的多次运行先在后端之外按 `subsampling_fraction` 抽取不同细胞子集，用于评估算法稳定性；
- 不同样本用于评估生物学复现性；
- 细胞不能作为独立生物学重复；
- 平衡混池结果只能作为描述性敏感性分析。

## 4. 必须预先冻结的内容

- 目标基因；
- 细胞亚群；
- WT/对照条件；
- 纳入的注释置信度；
- 基因宇宙及技术基因排除规则；
- 每样本细胞数上下限；
- 目标表达门槛；
- 网络数、网络抽样细胞数、主成分数、网络分位数；
- tensor rank、随机种子、`subsampling_fraction` 和重复次数；
- FDR 与重复/样本复现阈值。

不得看到结果后为某个目标单独改变参数。

## 5. 结果的正确含义

`distance`、`Z`、`FC` 和综合影响分数反映 WT 与虚拟 KO 网络中同一基因的网络状态差异。距离本身没有正负方向。因此：

- 可以说“网络扰动较强”“受到虚拟敲除影响”；
- 不可以说“预测上调”或“预测下调”；
- 网络边图展示的是重复出现的 WT 网络拓扑背景，不证明真实直接结合；
- 富集分析只说明受影响基因集合的通路过度代表。

## 6. 单图目录

每个目标基因 × 细胞亚群独立输出：

- `VirtualKO_rank__*`：共识影响基因排序；
- `VirtualKO_sample_support__*`：样本支持热图；
- `VirtualKO_target_expression__*`：目标表达与可评价性；
- `VirtualKO_manifold__*`：WT–KO 网络状态位移；
- `VirtualKO_network__*`：目标中心 WT 网络背景；
- `VirtualKO_run_similarity__*`：重复运行稳定性；
- `VirtualKO_pathways__*`：受影响基因通路富集。

每张图都必须有独立 PDF、SVG、600 dpi TIFF/PNG、183 mm proof、参数 YAML、plot RDS、Source Data 和视觉 QA。

## 7. 最低验证策略

1. 先用包内小型模拟数据完成函数和输出 smoke test；
2. 使用具有真实 WT/KO 标签的公共数据验证目标及下游影响的一致性；
3. 使用独立样本或独立数据集检查共识基因和通路；
4. 关键机制必须由真实扰动实验、蛋白/功能实验或外部 perturb-seq 证据验证。

## 8. 不可替代的边界

- 不能替代 CRISPR、siRNA、Perturb-seq；
- 不能直接证明直接调控或因果；
- 不能据此选择临床药物；
- 目标在选定细胞群中表达不足时必须输出 `NOT_EVALUABLE`；
- 只有一个可评价样本时必须标为 `Single-sample-descriptive`。


## 9. 本版相对基础代码的优化

- 对目标符号、目标表达、样本数、细胞数和基因宇宙执行显式门控；
- 支持 `targets_path` 对特定目标限定 `subset_value`；
- 在后端调用前执行外层重复下采样，避免重复稳定性完全依赖后端内部随机过程；
- 兼容 `X_/Y_` 与 `WT_/KO_` 两类 manifold 行名前缀，以及 `WT/KO` 与 `X/Y` 网络槽位；
- 验证 `diffRegulation` 必需字段，异常输出写入 run manifest 而不是继续作图；
- 分离样本内重复稳定性、跨样本复现性和平衡混池描述性敏感性分析。
