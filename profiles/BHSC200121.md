## Run the formal plasma workflow

### 1. Derive or read the frozen rule

Prefer the already frozen rule. Re-derive only when explicitly requested and record all input hashes.

Run:

`Results/Final results/17_DERIVE_FREEZE_TRANSFERABLE_PLASMA_RULE_FROM_MM5_V1.R`

Use MM5 as the derivation case and MM1-MM4 as internal transfer-audit cases. Do not call MM5 an independent validation case.

Define the plasma-positive programme as:

- surface core: `CD38, SLAMF7, SDC1, TNFRSF17`;
- secretory programme: `MZB1, DERL3, FKBP11, SEC11C, XBP1, JCHAIN, PRDM1, IRF4`;
- positive score: the larger of the two module scores.

Define the competing score as the maximum of predeclared T, NK, B, myeloid, erythroid, megakaryocyte and stromal/endothelial programmes. Define lineage margin as `positive score - competing score`.

Explicitly exclude all outcome genes from identity derivation:

`HLA-A, HLA-B, HLA-C, B2M, PSMB8, PSMB9, PSMB10, ERAP1, ERAP2, TAP1, TAP2, TAPBP, CALR, CANX, PDIA3`.

Keep these thresholds frozen:

- high-confidence positive score >= `0.2477`;
- lineage margin >= `0`;
- supported cluster size >= `20` cells;
- supported cluster Tier-1 fraction >= `0.07`;
- dropout-rescue positive score >= `0`;
- dropout-rescue lineage margin >= `0`;
- dropout-rescue plasma detection fraction >= `0.15`.

Always require QC pass and singlet status. Never relax competing-lineage exclusion. Define formal plasma as:

`plasmacyte_high_confidence + plasmacyte_supported_dropout_rescue`.

Retain all other cells as review/non-plasma rather than forcing assignment.

## Build the formal MHC-I/APM analysis

Run in order:

1. `Results/Final results/21_RESULT_REFRAMING_PREFLIGHT_V1.R`
2. `Results/Final results/22_REBUILD_BIOSAFE_MHCI_MAIN_EXTENDED_V2.R`
3. `Results/Final results/24_QA_REFRAMED_MANUSCRIPT_FIGURES_V2.R`

Calculate four prespecified readouts:

1. HLA-B/C: `HLA-B, HLA-C`;
2. classical HLA-I heavy chain: `HLA-A, HLA-B, HLA-C`;
3. canonical MHC-I complex: `HLA-A, HLA-B, HLA-C, B2M`;
4. APM execution machinery: `PSMB8, PSMB9, PSMB10, ERAP1, ERAP2, TAP1, TAP2, TAPBP, CALR, CANX, PDIA3`.

Make patient-level paired effect the main evidence. Report `EMM - IMM` effect sizes for every patient, retain positive and negative directions, and use cell bootstrap only as descriptive sampling stability. Do not report cell-level P values as formal evidence.

Use these canonical MHC-I/APM pairs only as drift checkpoints:

| Patient | Canonical MHC-I delta | APM delta |
|---|---:|---:|
| MM1 | +0.5287 | +0.4072 |
| MM2 | -0.2256 | -0.0029 |
| MM3 | NA | NA |
| MM4 | +0.1803 | +0.0935 |
| MM5 | +1.2524 | +0.3994 |

Frame the result as patient-specific MHC-I/APM transcriptional remodelling, not universal attenuation. Do not claim that an RNA score proves surface MHC-I loss, antigen-presentation failure or causality.

Run all prespecified robustness definitions without direction-based selection:

- high-confidence plasma only;
- high-confidence plus supported dropout rescue;
- overall formal plasma;
- common-support matched clusters;
- SDC1-stratified/matched sensitivity when supported.

Do not use a trajectory or outcome-guided endpoint as main evidence. If a descriptive IMM-EMM axis is explicitly requested, fit it per patient with MHC-I/APM and competing-lineage/outcome features excluded; report all supported EMM branches and abandon the axis if unstable.

Run:

1. `Results/Final results/11_ANNOTATE_UNSELECTED_EMM_T_NK_V1.R`
2. `Results/Final results/23_REBUILD_EMM_CYTOTOXIC_LYMPHOID_MAIN_EXTENDED_V2.R`
3. `Results/Final results/24_QA_REFRAMED_MANUSCRIPT_FIGURES_V2.R`

Start from original unselected EMM full-cell objects. Use positive T/cytotoxic lymphoid evidence and explicit plasma, B, myeloid and stromal competing-lineage exclusion. Never define lymphocytes as the complement of plasma cells.

Display only validated states:

- Effector T;
- Exhaustion-associated T;
- Gamma-delta/NKT-like.

Do not rename Gamma-delta/NKT-like as conventional NK without an independently validated conventional NK cluster. Retain ambiguous, doublet and other candidate cells in Source Data even when they are hidden from the main embedding.

- >=30 cells: main aggregate/pseudobulk;
- 10-29 cells: descriptive low-n;

## Handle historical and exploratory branches

Keep these branches separate from formal inference:

- strict three-gene Primary/Sensitivity annotation;
- IMM cluster rescue and site-balanced/borderline rescue;
- historical reference/manual bubble-plot annotation;
- MM5 exact-overlap or high-overlap cluster transfer to MM1-MM5;
- SPATS2/CXCR4, adhesion, MAPK/ERK and p38-MAPK analyses;
- IFN-JAK/STAT-NLRC5 expression and regulatory-score analyses.

For any exploratory branch:

1. use an independent script and output folder;
2. freeze genes, thresholds and fitting parameters before viewing outcomes;
3. exclude the studied outcome from identity selection;
4. label every figure, table and report `Exploratory`;
5. retain all patients and directions;
6. avoid causal or clinically validated language;
7. never overwrite or relabel formal RDS.

When asked to reproduce the historical manual annotation exactly, state that visual marker-based cluster labels lack a deterministic cell-level threshold and are suitable for exploratory reproduction, not as the formal annotation standard.

1. inventory all files and classify original/reference, formal, historical, exploratory, code, figures, Source Data and documentation;
2. explicitly state when the archive begins at Seurat-RDS rather than FASTQ level;
3. create per-file size and SHA-256 manifests;
4. include a detailed project Markdown and restore guide;
5. use UTF-8 ZIP64 store mode for already-compressed large RDS;
6. read every archive entry back and compare size and SHA-256;
