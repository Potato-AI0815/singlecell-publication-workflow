# Security Policy

This project processes local research data and executes third-party R packages. Do not run untrusted configuration files, scripts or serialized R objects.

Potential security issues include arbitrary code execution through malicious RDS/R scripts, unsafe paths, dependency supply-chain compromise and accidental exposure of patient data in logs or GitHub issues.

## Reporting a vulnerability

Please report security vulnerabilities privately to the Potato-AI project:

**939191004@qq.com**

Please do not publicly disclose an unresolved vulnerability before the maintainer has had a reasonable opportunity to investigate and respond.
